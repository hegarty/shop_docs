# Roadmap

- [`initial-prompt.md`](initial-prompt.md) — the original brief this whole platform was
  commissioned from, verbatim. Kept as a historical reference: when a decision seems
  arbitrary, check here first for the constraint that actually drove it (cost ceiling,
  security posture, language/platform choices, etc.) before assuming it needs revisiting.
- [`milestones.md`](milestones.md) — the living breakdown of that brief into milestones and
  tasks, with current status. This is the file to update as work completes or scope
  changes — the initial prompt itself never changes.

For "what's actually pushed vs. still local, what's broken, what's next," see
[`../SESSION.md`](../SESSION.md) instead — that's the day-to-day operating status. This
roadmap folder is the longer-arc plan; `SESSION.md` is the more volatile "where are we
right now."
