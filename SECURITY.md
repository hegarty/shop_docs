# Security Policy

This is a documentation-only repository — no application code, no secrets, no runtime
surface of its own. If you find a document here that describes a security control
inaccurately (e.g. this doc set claiming a protection exists that the actual code doesn't
implement), please report it the same way as a code vulnerability: GitHub's private
vulnerability reporting for this repository, or me@terencehegarty.com.

For vulnerabilities in the platform's actual code, report against the relevant service
repo (`shop_ingestor`, `shop_analytics`, `shop_notifier`, `shop_platform`) instead.
